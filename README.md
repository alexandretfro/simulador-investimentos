# Simulador de Investimentos (Android)

1. Crie um repositório no GitHub e envie esta pasta.
2. Em Actions, o workflow "Gerar APK" roda sozinho.
3. Ao terminar, baixe o artefato simulador-apk e instale o app-debug.apk no celular (permita fontes desconhecidas).

O simulador fica em app/src/main/assets/index.html.
